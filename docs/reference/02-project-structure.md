# Project Structure

Directory layout, file naming conventions, and import order.

## Directory Layout

```
src/
├── resume/           # Resume section components
│   ├── about.tsx
│   ├── education.tsx
│   ├── experience.tsx
│   ├── skills.tsx
│   ├── projects.tsx
│   └── *.test.tsx         # Component tests
├── ui/                # Shared layout, icons, and theme recipes
│   ├── layout.tsx
│   ├── sidebar.tsx / sidebar.recipe.ts
│   ├── footer.tsx
│   ├── error-section.tsx
│   ├── lang-icon.tsx
│   ├── social-icon.tsx
│   ├── use-icon-class.ts
│   ├── common.recipes.ts  # Shared PandaCSS recipes
│   ├── icon.recipes.ts    # Icon recipes
│   └── *.test.tsx
├── routes/           # TanStack Router file-based routes
│   ├── __root.tsx    # Root layout (wraps all routes)
│   └── index.tsx     # Homepage route (/), renders resume sections
├── test-utils/       # Testing utilities
│   ├── setups/       # Test environment setup
│   ├── mock-metadata.ts
│   └── render-wrapper.tsx
└── img/              # Static images
```

## File Naming

- **kebab-case** for all files: `user-profile.tsx`, `use-metadata.ts`
- **Component files**: `component-name.tsx`
- **Test files**: `component-name.test.tsx` (co-located with source)
- **Recipe files**: `component-name.recipe.ts` / `*.recipes.ts` (PandaCSS recipes, registered in `panda.config.ts`)
- **Hook files**: `use-hook-name.ts`

## Generated Files (Do Not Edit)

| File/Directory          | Generator                                      | Notes                                            |
| ----------------------- | ---------------------------------------------- | ------------------------------------------------ |
| `styled-system/`        | [PandaCSS](https://panda-css.com)              | CSS utilities, generated by `pnpm panda:codegen` |
| `src/route-tree.gen.ts` | [TanStack Router](https://tanstack.com/router) | Route tree, auto-generated during dev            |
| `__snapshots__/`        | [Vitest](https://vitest.dev)                   | Test snapshots, update with `pnpm test -- -u`    |
| `dist/`                 | [Vite](https://vite.dev)                       | Production build output                          |
| `coverage/`             | [Vitest](https://vitest.dev)                   | Test coverage reports                            |

## Import Order

Organized automatically by [Oxfmt](https://oxc.rs/docs/guide/usage/formatter) `sortImports`:

1. [React](https://react.dev) imports
2. External library imports
3. Internal module imports
4. Type imports (with `import type`)
5. Style/CSS imports

```typescript
import { useState } from 'react';
import { useRouter } from '@tanstack/react-router';
import { calculateTotal } from '../utils';
import type { User } from '../types';
import { css } from '../../styled-system/css';
```
